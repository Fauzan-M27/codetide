HTML Lanjut — Link, Frame, Tabel

Setelah memahami struktur dasar HTML, sekarang saatnya belajar membuat halaman yang saling terhubung dan menampilkan data terstruktur. Materi ini membahas tiga elemen penting: link (tautan), tabel, dan iframe.

1. Link Internal (dalam satu halaman)

Link internal digunakan untuk berpindah ke bagian lain di halaman yang sama, misalnya tombol "kembali ke atas". Caranya dengan memberi id pada elemen tujuan, lalu mengarahkan href ke #id tersebut:

<h1 id="atas">Judul</h1>

<a href="#atas">Kembali ke Atas</a>

Perhatikan: nilai href diawali tanda pagar (#) diikuti nama id elemen yang dituju — tanpa spasi dan harus sama persis dengan id aslinya (huruf besar/kecil berpengaruh).

2. Link Eksternal (ke halaman lain)

Untuk tautan ke website lain, isi href dengan URL lengkap. Supaya halaman tujuan terbuka di tab baru (tidak menggantikan halaman yang sedang dibuka), tambahkan atribut target="_blank":

<a href="https://www.google.com" target="_blank">Buka Google</a>

3. Tabel

Tabel digunakan untuk menampilkan data dalam bentuk baris dan kolom. Tiga tag utamanya: <table> sebagai pembungkus, <tr> (table row) untuk setiap baris, dan di dalam baris ada <th> (table header, untuk judul kolom) atau <td> (table data, untuk isi data biasa):

<table>
  <tr>
    <th>Nama</th>
    <th>Semester</th>
    <th>Jurusan</th>
  </tr>
  <tr>
    <td>Budi</td>
    <td>3</td>
    <td>PTIK</td>
  </tr>
</table>

Baris pertama biasanya berisi <th> sebagai judul kolom (ditampilkan tebal oleh browser secara default), sedangkan baris-baris berikutnya berisi <td> sebagai data sebenarnya.

4. Iframe

<iframe> digunakan untuk menampilkan halaman web lain di dalam halamanmu sendiri, seperti jendela kecil yang menampilkan konten dari sumber lain (video YouTube yang di-embed adalah contoh iframe):

<iframe src="https://www.example.com" width="400" height="300"></iframe>

Atribut src wajib diisi dengan alamat halaman yang ingin ditampilkan — tanpa ini, iframe akan kosong.

5. Menggabungkan Semuanya

Dalam praktiknya, sebuah halaman navigasi biasanya menggabungkan beberapa link, tabel data, dan kadang iframe sekaligus:

<nav>
  <a href="#profil">Profil</a>
  <a href="https://unm.ac.id" target="_blank">Website UNM</a>
</nav>

<h2 id="profil">Data Mahasiswa</h2>
<table>
  <tr><th>Nama</th><th>NIM</th></tr>
  <tr><td>Budi</td><td>12345</td></tr>
</table>

<iframe src="https://www.example.com" width="300" height="200"></iframe>

💡 Tips Sebelum Mengerjakan Soal

  • Link internal memakai #id, link eksternal memakai URL lengkap (https://...) — jangan tertukar.
  • target="_blank" hanya relevan untuk link eksternal; link internal tidak perlu atribut ini.
  • Setiap <tr> harus berisi jumlah sel (<th>/<td>) yang konsisten antar baris, supaya tabel tidak berantakan.
  • Jangan lupa atribut src pada <iframe> — tanpa itu, iframe tidak menampilkan apa-apa.
  • Di soal materi ini kamu akan membuat link internal, link eksternal, tabel 3x3, iframe, lalu menggabungkan ketiganya dalam satu halaman navigasi lengkap.

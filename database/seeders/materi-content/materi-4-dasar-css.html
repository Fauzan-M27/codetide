Dasar CSS — Selector & Properti

Kalau HTML adalah kerangka halaman, CSS (Cascading Style Sheets) adalah yang membuatnya tampil cantik — warna, ukuran teks, jarak antar elemen, dan seterusnya. Materi ini membahas tiga jenis selector dasar dan properti yang paling sering dipakai.

1. Cara Menulis CSS

CSS ditulis di dalam tag <style> (biasanya diletakkan di dalam <head>), dengan pola selector { properti: nilai; }:

<style>
  h1 {
    color: blue;
  }
</style>

2. Selector Tag

Selector tag menargetkan semua elemen dengan nama tag tertentu. Contoh di atas (h1 { color: blue; }) akan membuat semua <h1> di halaman menjadi biru.

3. Selector Class

Kalau kamu hanya ingin menata elemen tertentu (tidak semua), gunakan class. Beri atribut class pada elemen HTML, lalu di CSS targetkan dengan tanda titik (.) di depan nama class:

<p class="besar">Teks ini akan besar</p>

<style>
  .besar {
    font-size: 18px;
  }
</style>

Satu class bisa dipakai di banyak elemen sekaligus — cocok untuk gaya yang ingin diulang di beberapa tempat.

4. Selector Id

Id menargetkan satu elemen spesifik saja (id harus unik dalam satu halaman). Ditandai dengan tanda pagar (#) di CSS:

<div id="kotak">Kotak berwarna</div>

<style>
  #kotak {
    background-color: lightblue;
  }
</style>

5. Padding dan Margin

padding adalah jarak di dalam elemen (antara tepi elemen dan isinya), sedangkan margin adalah jarak di luar elemen (antara elemen itu dan elemen lain di sekitarnya):

.kartu {
  padding: 20px;
  margin: 10px;
}

Bayangkan padding seperti bantalan di dalam kotak, dan margin seperti jarak antar kotak-kotak yang berdekatan.

6. Menggabungkan Beberapa Selector dalam Satu Stylesheet

Dalam praktik nyata, satu halaman biasanya memakai kombinasi ketiga jenis selector sekaligus, masing-masing untuk kebutuhan berbeda:

<style>
  h1 {
    color: darkblue;
  }
  .intro {
    font-size: 16px;
    color: gray;
  }
  #footer {
    background-color: #eeeeee;
    padding: 10px;
  }
</style>

<h1>Judul Halaman</h1>
<p class="intro">Paragraf intro</p>
<div id="footer">Footer halaman</div>

💡 Tips Sebelum Mengerjakan Soal

  • Urutan prioritas: id lebih "kuat" dari class, dan class lebih "kuat" dari tag — kalau dua aturan bentrok pada elemen yang sama, yang lebih spesifik akan menang.
  • Jangan lupa titik dua (:) setelah nama properti dan titik koma (;) setelah nilai — ini kesalahan sintaks paling umum di CSS.
  • Nama class dan id ditulis tanpa spasi; gunakan tanda hubung (mis. nama-kelas) kalau butuh lebih dari satu kata.
  • Di soal materi ini kamu akan berlatih mengubah warna teks, ukuran font, background, padding/margin, dan terakhir menggabungkan ketiga jenis selector dalam satu halaman.

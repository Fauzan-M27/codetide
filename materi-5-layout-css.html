Layout & Interaksi CSS — Flexbox & Hover

Setelah menguasai dasar CSS, sekarang saatnya belajar menata tata letak (layout) beberapa elemen sekaligus, dan membuat tampilan yang merespons interaksi pengguna seperti saat kursor mouse diarahkan ke sebuah elemen (hover).

1. Flexbox — Menyusun Elemen Secara Horizontal

Secara default, elemen seperti <div> akan tersusun ke bawah (vertikal) satu per satu. Untuk membuatnya tersusun berdampingan (horizontal), gunakan display: flex pada elemen pembungkusnya:

<div class="container">
  <div>Box 1</div>
  <div>Box 2</div>
  <div>Box 3</div>
</div>

<style>
  .container {
    display: flex;
  }
</style>

Dengan display: flex pada .container, ketiga <div> anaknya otomatis tersusun berdampingan dari kiri ke kanan.

2. Gap — Jarak Antar Elemen Flex

Supaya elemen-elemen di dalam flex container tidak saling menempel, gunakan properti gap:

.container {
  display: flex;
  gap: 20px;
}

3. Hover dan Transisi

Pseudo-class :hover digunakan untuk mengubah gaya sebuah elemen saat kursor diarahkan ke atasnya. Agar perubahannya terasa halus (tidak tiba-tiba), tambahkan transition:

.btn {
  background-color: lightblue;
  border-radius: 8px;
  transition: all 0.3s ease;
}
.btn:hover {
  background-color: dodgerblue;
}

border-radius membuat sudut elemen jadi melengkung (semakin besar nilainya, semakin bulat). transition: all 0.3s ease; pada state normal (bukan di dalam :hover) memberi tahu browser untuk menganimasikan semua perubahan properti secara halus selama 0,3 detik — termasuk perubahan yang terjadi saat hover.

4. Layout Dua Kolom dengan Flexbox

Flexbox juga sering dipakai untuk membuat layout halaman, misalnya sidebar di samping konten utama:

<div class="layout">
  <aside class="sidebar">Sidebar</aside>
  <main class="content">Konten Utama</main>
</div>

<style>
  .layout {
    display: flex;
  }
  .sidebar {
    width: 200px;
  }
  .content {
    flex: 1;
  }
</style>

flex: 1 pada .content membuatnya mengisi sisa ruang yang tidak dipakai oleh sidebar.

5. Kesalahan Umum pada Flexbox dan Hover

Perhatikan potongan kode berikut — terlihat hampir benar, tapi ada masalah yang membuat tampilannya tidak sesuai harapan:

<!-- ❌ Salah: display masih "block", flexbox tidak akan bekerja -->
.card-container {
  display: block;
}

<!-- ❌ Kurang: tidak ada transition, jadi perubahan hover terasa patah-patah -->
.card {
  padding: 20px;
  border-radius: 10px;
}
.card:hover {
  box-shadow: 0 5px 15px rgba(0,0,0,0.3);
  transform: scale(1.05);
}

<!-- ✅ Benar -->
.card-container {
  display: flex;
  gap: 16px;
}
.card {
  padding: 20px;
  border-radius: 10px;
  transition: all 0.3s ease;
}

💡 Tips Sebelum Mengerjakan Soal

  • display: flex harus ditaruh pada elemen pembungkus (parent), bukan pada elemen yang ingin disusun (child).
  • Kalau efek hover terasa "patah-patah" atau tidak smooth, kemungkinan besar properti transition belum ditambahkan.
  • gap hanya berfungsi di dalam elemen yang sudah memakai display: flex (atau grid).
  • Soal terakhir materi ini berbentuk Bug Hunt — ada kartu interaktif dengan beberapa masalah (flexbox tidak jalan, hover tidak smooth, shadow tidak muncul) yang perlu kamu temukan dan perbaiki.

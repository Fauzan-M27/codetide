HTML Interaktif — Form & Media

Form adalah cara utama sebuah halaman web menerima masukan dari pengguna — mulai dari kolom login, kotak pencarian, sampai formulir pendaftaran. Materi ini membahas elemen-elemen form dan cara menghubungkannya dengan benar, karena kesalahan kecil (seperti label yang tidak terhubung) adalah bug yang paling sering terjadi di dunia nyata.

1. Form dan Input Teks

<form>
  <input type="text" name="nama">
</form>

<form> adalah pembungkus semua elemen input. <input type="text"> adalah kolom isian teks satu baris. Atribut name penting untuk menandai data apa yang dikirim saat form disubmit.

2. Select Dropdown

Untuk pilihan dari daftar tertutup (misalnya memilih jurusan), gunakan <select> dengan beberapa <option> di dalamnya:

<select name="jurusan">
  <option value="ptik">PTIK</option>
  <option value="pti">PTI</option>
  <option value="sipil">Teknik Sipil</option>
</select>

3. Textarea dan Label yang Terhubung

<textarea> dipakai untuk isian teks panjang (multi-baris), seperti kolom pesan. <label> memberi keterangan nama pada sebuah input — tapi supaya benar-benar terhubung (misalnya supaya klik pada label otomatis fokus ke input-nya), atribut for pada label harus sama persis dengan id pada input:

<label for="pesan">Pesan Anda</label>
<textarea id="pesan" name="pesan"></textarea>

Perhatikan: for="pesan" pada label harus cocok dengan id="pesan" pada textarea — bukan dengan name-nya. Ini adalah kesalahan paling umum yang membuat label "tidak nyambung" ke input-nya.

4. Gambar dan Tombol Submit

<img src="foto.jpg" alt="Foto profil mahasiswa">
<button type="submit">Kirim</button>

Atribut alt pada <img> wajib diisi dengan teks deskriptif — ini membantu pengguna dengan pembaca layar (screen reader) dan tetap tampil kalau gambar gagal dimuat. <button type="submit"> adalah tombol yang mengirim data form.

5. Checkbox dengan Label

Pola yang sama berlaku untuk checkbox — butuh id pada input dan for yang cocok pada label:

<input type="checkbox" id="setuju" name="setuju">
<label for="setuju">Saya setuju dengan syarat dan ketentuan</label>

6. Kesalahan Umum yang Sering Terjadi

Perhatikan baik-baik potongan kode form berikut — ada beberapa masalah yang sering luput diperhatikan:

<!-- ❌ Salah: label tidak terhubung ke input (tidak ada for/id) -->
<label>Nama</label>
<input type="text" id="nama">

<!-- ❌ Salah: for dan id tidak sama -->
<label for="email">Email</label>
<input type="text" id="emailField">

<!-- ❌ Salah: checkbox tidak punya id, label tidak punya for -->
<input type="checkbox">
<label>Setuju dengan syarat</label>

<!-- ✅ Benar -->
<label for="nama">Nama</label>
<input type="text" id="nama">

💡 Tips Sebelum Mengerjakan Soal

  • Selalu cek: nilai for pada label = nilai id pada input yang dituju. Keduanya harus sama persis (termasuk huruf besar/kecil).
  • Setiap elemen input yang ingin dilabeli (text, textarea, checkbox) butuh atribut id sendiri.
  • alt pada gambar bukan opsional — selalu isi dengan deskripsi yang jelas.
  • Soal terakhir materi ini berbentuk Bug Hunt — kamu akan diberi form yang sudah punya beberapa masalah seperti di atas, dan tugasmu adalah menemukan serta memperbaikinya satu per satu.

Manipulasi DOM & Logika Sederhana

DOM (Document Object Model) adalah representasi halaman HTML yang bisa "diutak-atik" oleh JavaScript secara langsung — mengubah warna, menyembunyikan elemen, atau menambah konten baru, semuanya tanpa perlu memuat ulang halaman. Materi terakhir ini juga membahas logika kondisional dan perulangan, dua konsep dasar pemrograman yang penting.

1. Mengubah Style Elemen via JavaScript

Setiap elemen HTML yang ditangkap dengan getElementById punya properti .style yang bisa diubah langsung dari JavaScript:

<div id="box" style="width:200px;height:200px;background:gray;"></div>
<button id="btnUbah">Ubah Warna</button>

<script>
  document.getElementById("btnUbah").addEventListener("click", function() {
    document.getElementById("box").style.backgroundColor = "yellow";
  });
</script>

Perhatikan penamaan di JavaScript: properti CSS background-color (dengan tanda hubung) ditulis sebagai backgroundColor (tanpa tanda hubung, huruf kedua jadi kapital) saat diakses lewat .style.

2. Toggle Class

Daripada mengubah style satu per satu, cara yang lebih rapi adalah menyiapkan class di CSS, lalu menambah/menghapusnya lewat JavaScript dengan classList.toggle():

<style>
  .active { color: red; font-weight: bold; }
</style>

<p id="teks">Teks ini bisa berubah</p>
<button id="btnToggle">Toggle</button>

<script>
  document.getElementById("btnToggle").addEventListener("click", function() {
    document.getElementById("teks").classList.toggle("active");
  });
</script>

toggle() otomatis menambahkan class kalau belum ada, atau menghapusnya kalau sudah ada — jadi satu baris kode saja cukup untuk "menyalakan-mematikan" sebuah gaya.

3. Menampilkan/Menyembunyikan Elemen

Untuk menyembunyikan elemen sepenuhnya (bukan sekadar mengubah warnanya), ubah properti display menjadi "none", dan kembalikan ke semula (misalnya "block") untuk menampilkannya lagi:

<div id="konten">Konten yang bisa disembunyikan</div>
<button id="btnToggle">Tampil/Sembunyikan</button>

<script>
  document.getElementById("btnToggle").addEventListener("click", function() {
    const konten = document.getElementById("konten");
    if (konten.style.display === "none") {
      konten.style.display = "block";
    } else {
      konten.style.display = "none";
    }
  });
</script>

4. Kondisi If/Else untuk Validasi

if/else digunakan untuk menjalankan kode yang berbeda tergantung sebuah kondisi benar atau salah:

<input type="number" id="usia" placeholder="Masukkan usia">
<button id="btnCek">Cek</button>
<p id="hasil"></p>

<script>
  document.getElementById("btnCek").addEventListener("click", function() {
    const usia = Number(document.getElementById("usia").value);
    if (usia >= 17) {
      document.getElementById("hasil").innerText = "Boleh daftar";
    } else {
      document.getElementById("hasil").innerText = "Belum boleh daftar";
    }
  });
</script>

Jangan lupa ubah nilai input (yang berupa teks) menjadi angka dengan Number(...) sebelum dibandingkan — kalau tidak, perbandingan >= bisa memberi hasil yang tidak terduga.

5. Perulangan For untuk Membuat Daftar Dinamis

Perulangan for memungkinkan kita menjalankan kode yang sama berkali-kali — misalnya untuk membuat beberapa <li> sekaligus tanpa menulisnya satu per satu:

<ul id="daftar"></ul>

<script>
  const daftar = document.getElementById("daftar");
  for (let i = 1; i <= 5; i++) {
    const item = document.createElement("li");
    item.innerText = i;
    daftar.appendChild(item);
  }
</script>

Setiap putaran perulangan membuat satu elemen <li> baru (createElement), mengisi teksnya (innerText), lalu menambahkannya ke dalam <ul> (appendChild).

💡 Tips Sebelum Mengerjakan Soal

  • Properti CSS dengan tanda hubung (mis. background-color) ditulis tanpa tanda hubung dan huruf kapital di tengah (backgroundColor) saat diakses lewat JavaScript.
  • classList.toggle() lebih rapi dipakai daripada mengatur banyak properti .style satu per satu.
  • Selalu ubah input angka dengan Number(...) sebelum dipakai dalam perbandingan if, supaya tidak salah hasil.
  • Soal terakhir materi ini adalah Clone Challenge: membuat daftar tugas (todo list) sederhana menggunakan perulangan for, menggabungkan semua konsep manipulasi DOM yang sudah dipelajari di materi ini.

Event Handling

"Event" adalah kejadian yang terjadi di halaman web — pengguna mengklik tombol, mengetik di kolom input, atau mengirim form. JavaScript bisa "mendengarkan" kejadian-kejadian ini dan menjalankan kode sebagai responsnya. Ini yang membuat website terasa hidup dan interaktif.

1. Event Listener Dasar — Klik

Untuk menjalankan kode saat sebuah tombol diklik, gunakan addEventListener:

<button id="btn">Klik Saya</button>
<p id="teks">Teks awal</p>

<script>
  document.getElementById("btn").addEventListener("click", function() {
    document.getElementById("teks").innerText = "Tombol sudah diklik!";
  });
</script>

Polanya: tangkap elemen dengan getElementById, panggil .addEventListener("nama_event", function() { ... }), lalu tulis apa yang ingin terjadi di dalam fungsi tersebut.

2. Event Listener pada Beberapa Elemen

Kamu bisa memasang event listener pada beberapa tombol sekaligus, masing-masing dengan aksi yang berbeda:

<button id="btn1">Tombol 1</button>
<button id="btn2">Tombol 2</button>
<p id="output">-</p>

<script>
  document.getElementById("btn1").addEventListener("click", function() {
    document.getElementById("output").innerText = "Tombol 1 ditekan";
  });
  document.getElementById("btn2").addEventListener("click", function() {
    document.getElementById("output").innerText = "Tombol 2 ditekan";
  });
</script>

3. Event Keyup — Live Preview saat Mengetik

Event keyup terjadi setiap kali pengguna melepas tombol keyboard (setelah mengetik satu karakter). Berguna untuk fitur "live preview":

<input type="text" id="inputan">
<p id="preview"></p>

<script>
  document.getElementById("inputan").addEventListener("keyup", function() {
    const nilai = document.getElementById("inputan").value;
    document.getElementById("preview").innerText = nilai;
  });
</script>

Perhatikan: untuk mengambil teks yang diketik di dalam <input>, gunakan .value — berbeda dari elemen seperti <p> yang pakai .innerText.

4. Event Submit dan Mencegah Reload Halaman

Secara default, menekan tombol submit pada form akan membuat halaman reload (memuat ulang). Untuk mencegah ini — misalnya supaya kita bisa memproses data dengan JavaScript tanpa kehilangan tampilan — gunakan event.preventDefault():

<form id="myForm">
  <input type="text" name="nama">
  <button type="submit">Submit</button>
</form>
<p id="pesan"></p>

<script>
  document.getElementById("myForm").addEventListener("submit", function(event) {
    event.preventDefault();
    document.getElementById("pesan").innerText = "Form berhasil dikirim!";
  });
</script>

Perhatikan parameter event pada fungsi — ini mewakili "kejadian" yang baru terjadi, dan event.preventDefault() memberi tahu browser untuk tidak melakukan perilaku bawaannya (reload halaman).

5. Menggabungkan Beberapa Event — Kalkulator Sederhana

Fitur yang lebih kompleks biasanya menggabungkan beberapa event sekaligus. Contoh kalkulator sederhana yang menggabungkan input angka dan klik tombol:

<input type="number" id="angka1">
<input type="number" id="angka2">
<button id="btnTambah">Tambah</button>
<p id="hasil"></p>

<script>
  document.getElementById("btnTambah").addEventListener("click", function() {
    const a = Number(document.getElementById("angka1").value);
    const b = Number(document.getElementById("angka2").value);
    document.getElementById("hasil").innerText = "Hasil: " + (a + b);
  });
</script>

Perhatikan penggunaan Number(...) untuk mengubah nilai input (yang secara default berupa teks) menjadi angka, supaya operator + benar-benar menjumlahkan, bukan menggabungkan teks.

💡 Tips Sebelum Mengerjakan Soal

  • Nama event ditulis dalam tanda kutip dan huruf kecil: "click", "keyup", "submit" — bukan "Click" atau tanpa kutip.
  • Untuk <input>, ambil nilainya dengan .value; untuk elemen teks biasa seperti <p>, gunakan .innerText.
  • Event submit dipasang pada elemen <form>, bukan pada tombolnya — dan jangan lupa event.preventDefault() kalau tidak ingin halaman reload.
  • Soal terakhir materi ini adalah Clone Challenge: kamu akan diminta membuat kalkulator sederhana dari nol berdasarkan contoh yang diperlihatkan, dengan menggabungkan event klik dan input seperti pada contoh di atas.

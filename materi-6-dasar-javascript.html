Dasar JavaScript — Variabel & Output

JavaScript adalah bahasa pemrograman yang membuat halaman web menjadi interaktif — bisa merespons klik, mengubah tampilan secara dinamis, dan menghitung sesuatu secara langsung di browser. Materi ini membahas dasar-dasar JavaScript: variabel, output, dan fungsi.

1. Variabel

Variabel adalah "wadah" untuk menyimpan data. Gunakan let untuk variabel yang nilainya bisa berubah, atau const untuk nilai yang tetap:

let nama = "Budi";
const semester = 3;

2. Menampilkan Output ke Halaman

Untuk menampilkan nilai variabel ke dalam elemen HTML, gunakan document.getElementById() untuk "menangkap" elemen tujuan, lalu atur innerText-nya:

<p id="output"></p>

<script>
  let nama = "Budi";
  document.getElementById("output").innerText = nama;
</script>

Setelah kode ini berjalan, teks "Budi" akan muncul di dalam elemen <p id="output">.

3. Menggabungkan Beberapa Variabel

Variabel bisa digabung menjadi satu kalimat menggunakan tanda plus (+):

let nama = "Budi";
let semester = 3;
let kalimat = "Nama saya " + nama + ", semester " + semester;
document.getElementById("output").innerText = kalimat;

4. Operator Aritmatika

JavaScript juga bisa melakukan perhitungan matematika langsung dengan operator seperti + (tambah), - (kurang), * (kali), dan / (bagi):

let a = 5;
let b = 3;
let hasil = a + b;
document.getElementById("output").innerText = "Hasil: " + hasil;

5. Template Literal

Cara yang lebih rapi untuk menggabungkan teks dan variabel adalah dengan template literal — tanda kutip backtick (`, bukan kutip biasa) yang memungkinkan variabel disisipkan langsung dengan ${}:

const nama = "Budi";
const umur = 20;
let kalimat = `Nama saya ${nama}, umur ${umur} tahun`;
document.getElementById("output").innerText = kalimat;

Template literal lebih mudah dibaca dibanding menyambung banyak tanda +, terutama kalau variabelnya banyak.

6. Fungsi dengan Parameter

Fungsi adalah blok kode yang bisa dipanggil berkali-kali dengan input (parameter) yang berbeda-beda. Fungsi bisa return (mengembalikan) sebuah nilai:

function sapa(nama) {
  return "Halo, " + nama + "!";
}

document.getElementById("output").innerText = sapa("Budi");

Fungsi sapa di atas menerima satu parameter (nama) dan mengembalikan kalimat sapaan. Memanggilnya dengan nama berbeda (sapa("Ani")) akan menghasilkan output yang berbeda pula, tanpa perlu menulis ulang kodenya.

💡 Tips Sebelum Mengerjakan Soal

  • Kode JavaScript selalu ditulis di dalam tag <script></script>.
  • Setiap baris perintah JavaScript sebaiknya diakhiri titik koma (;) — ini bukan wajib mutlak, tapi praktik yang baik dan menghindari error tak terduga.
  • Template literal memakai tanda backtick ` (biasanya di pojok kiri atas keyboard, satu tombol dengan tilde ~) — bukan kutip satu (') atau kutip dua (").
  • Di soal materi ini kamu akan berlatih mendeklarasikan variabel, menampilkannya ke halaman, menggabungkan variabel, memakai operator aritmatika, template literal, dan terakhir membuat fungsi dengan parameter.
